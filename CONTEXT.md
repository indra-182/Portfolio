# Portfolio Experience

This context describes the visual language and interaction concepts shared by the portfolio homepage and project case studies.

## Language

**Editorial brutalism**:
A visual direction that combines editorial hierarchy with brutalist structure: oversized typography, rigid grids, sharp rules, flat surfaces, and a restrained high-contrast palette.
_Avoid_: Neobrutalism as a separate visual system, soft card-heavy UI, glassmorphism

**Signal orange**:
The portfolio's primary accent for actions, active navigation, links, and visual emphasis. Status colors remain distinct from the signal accent.
_Avoid_: Treating every accent color as interchangeable

**Section rail**:
The persistent desktop navigation that lets visitors move between the portfolio's single-page sections. On smaller screens it becomes an overlay navigation drawer.
_Avoid_: Sidebar as a separate content area

**Pointer glow**:
A decorative halo that follows fine-pointer movement and disappears for coarse pointers or reduced-motion preferences. It never replaces the cursor or participates in interaction.
_Avoid_: Canvas cursor, custom cursor, interaction layer

**Resume CTA**:
The downloadable résumé action presented in the hero and contact section, not in the global footer.
_Avoid_: Footer résumé link
